# Single point LAMMPS forces evaluation

The LAMMPS-side counterpart of `single_point_gmx/`: `singlepoint.in` reads the converted topology
and runs `run 0` — zero timesteps, i.e. just evaluate forces once for the structure as given —
dumping per-atom forces to `forces.lammpstrj`.

One thing worth noticing if you inspect `singlepoint.in`: its `pair_coeff` table (one line per
atom type, giving that type's Lennard-Jones ε and σ) is written out explicitly by hand, not read
from `converted.lmp`. This is because InterMol's LAMMPS writer doesn't emit a `Pair Coeffs`
section in the data file for this force field — so whoever last regenerated this tutorial had to
transcribe the current `custom-ffnonbonded.itp`'s ε/σ values into this table manually, matching
each LAMMPS atom-type ID to its OPLS type via `converted.lmp`'s `Atoms`/`Masses` sections and
`molecule.itp`. **If you change the force-field library (e.g. update atom parameters) and
regenerate `converted.lmp`, this table does not update itself and must be rebuilt by hand** —
unlike every other file in this pipeline, which is fully regenerated by rerunning the relevant
tool.

## Provenance

    cp ../../converted.lmp .

## Run

    lmp -in singlepoint.in

    bash extract_forces.sh

`extract_forces.sh` reformats `forces.lammpstrj` into `forces_lmp_raw.dat` (LAMMPS's native
kcal/(mol·Å) units) and then `forces_lmp.dat` (converted ×41.84 to kJ/(mol·nm), matching GROMACS's
units — see the parent `forces/README.md` for why).
